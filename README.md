# Logistics Performance Analysis

## Project Overview

This project analyzes logistics performance using SQL and Excel. The goal is to compare shipping carriers based on delivery costs, on-time delivery rates, and average delivery times.

The project uses a small synthetic dataset created for learning and demonstration purposes.

## Tools Used

SQLite: Store and organize logistics data.

SQL: Query and analyze shipping performance.

Excel: Create charts and a performance dashboard.

DB Browser for SQLite: Manage the database and execute SQL queries.

## Key Performance Indicators (KPIs)

The analysis focuses on three main metrics:

Total Delivered Orders: 6

Overall On-Time Delivery Rate: 66.7%

Average Delivery Time: 2.67 days

## Key Findings

1. Shipping Cost

Carrier B has the lowest average shipping cost at $9.75 per order.

2. On-Time Delivery Performance

Carrier C has the highest on-time delivery rate at 100%.

3. Delivery Speed

Carrier C has the shortest average delivery time at 2 days.

4. Cost and Performance Comparison

Carrier B offers the lowest average shipping cost, while Carrier C performs best in delivery speed and on-time delivery.

## SQL Skills Demonstrated

- SELECT and WHERE

- JOIN

- GROUP BY and ORDER BY

- COUNT and AVG

- CASE WHEN

- ROUND

- Date calculations using JULIANDAY

## Data Source

This project uses a synthetic logistics dataset for SQL and Excel practice. The dataset includes 6 delivered orders across 3 carriers.

The results are for demonstration purposes and do not represent real shipping companies.
